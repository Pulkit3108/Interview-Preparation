
What are Smart pointers in C++?
Smart pointers in C++ are objects that manage the lifetime of dynamically allocated memory. They help ensure that memory is properly deallocated when it is no longer needed, preventing memory leaks and dangling pointers. Smart pointers are part of the C++ Standard Library and are defined in the <memory> header.
std::unique_ptr: Exclusive ownership, cannot be copied, can be moved.
std::shared_ptr: Shared ownership, reference counting, can be copied.
std::weak_ptr: Non-owning reference, used to break circular references
What is a dangling pointer?
A dangling pointer is a pointer that references a memory location that has been deallocated or freed. Accessing or dereferencing a dangling pointer can lead to undefined behavior, including program crashes, data corruption, and security vulnerabilities.
Avoid dangling pointers by setting pointers to nullptr after deallocation, using smart pointers, and careful memory management.
What is the difference between an integer pointer and character pointer
Integer Pointer (int*):
Points to an int type variable.
Typically moves 4 bytes ahead in memory when incremented.
Dereferencing gives the value of the integer it points to.
Character Pointer (char*):
Points to a char type variable.
Moves 1 byte ahead in memory when incremented.
Dereferencing gives the value of the character it points to.
What is the difference between nullptr and NULL?
NULL:
Defined as 0 or ((void*)0).
Integer constant with a value of zero.
Can cause ambiguity in function overloading.
Commonly used in C and early C++.
nullptr:
Introduced in C++11.
Has its own type, std::nullptr_t.
Preferred way to represent null pointers in modern C++.
Eliminates ambiguity in function overloading.
What is a mutable keyword in c++ what is it's use case?
The mutable keyword in C++ is used to allow a member of an object to be modified even if the object is declared as const. This is particularly useful in scenarios where you want to maintain logical constness but need to allow certain members to be modified.
It is useful for caching, lazy initialization, debugging, and logging.
It helps maintain logical constness while allowing certain members to be updated.
What are inline functions in c++?
Inline functions are expanded in line at the point of call, reducing function call overhead.
Syntax: Use the inline keyword before the function definition.
Advantages: Reduced function call overhead, potential for better optimization.
Disadvantages: Potential for code bloat, compiler may ignore the inline request.
Use Cases: Small, frequently called functions, performance-critical code.

template <typename T>
bool isUniqueString(const T &input) {
    // Check for nullptr
    if constexpr (is_same_v<T, nullptr_t>) {
        return false;
    }
    // Convert input to string if possible
    string strInput;
    if constexpr (is_same_v<T, string>) {
        strInput = input;
    } else if constexpr (is_same_v<T, char>) {
        strInput = string(1, input);
    } else if constexpr (is_arithmetic_v<T>) {
        strInput = to_string(input);
    } else {
        // If input is not a string, char, or arithmetic type, return false
        return false;
    }
    // Check for uniqueness in the string representation
    unordered_map<char, int> charMap;
    for (char ch : strInput) {
        if (charMap.find(ch) != charMap.end()) {
            return false;
        }
        charMap[ch] = 1;
    }
    return true;
}
