### Study Guidance

Start with core language and JVM behavior, then collections and exceptions. Review concurrency only
after object contracts and the Java Memory Model are clear. Treat coding exercises as prompts: state
assumptions, discuss complexity, handle edge cases, and then compare the implementation with the
provided answer.
